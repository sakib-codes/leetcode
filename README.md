# LeetCode Problems

A personal collection of LeetCode solutions written in Dart, C, C++, and Python.

## Goal

Solve at least **one LeetCode problem every day**. Solving more than one is encouraged when time and energy allow.

The main goals are to:

- Build a consistent daily problem-solving habit.
- Learn and strengthen data structures and algorithms (DSA).
- Practice solving problems in Dart, C, C++, and Python.
- Improve the clarity, efficiency, and readability of each solution.

## Repository Structure

Solutions are organized by difficulty:

```text
Easy/
Medium/
Hard/
```

Each solution is kept in its own source file. Where useful, file names describe the problem and the approach used. Solutions can be added in any of the target languages.

## Running a Solution

Run a solution using the toolchain for its language. For example, from the repository root:

```bash
# Dart
dart run Easy/PalindromeOfNumber.dart

# C
gcc Easy/problem.c -o /tmp/problem && /tmp/problem

# C++
g++ Easy/problem.cpp -o /tmp/problem && /tmp/problem

# Python
python3 Easy/problem.py
```

Replace the file path with the solution you want to run.

## Progress Guidelines

- Complete at least one problem each day.
- Prefer understanding the solution over simply finishing it.
- Identify the data structure and algorithm used in each solution.
- Consider time and space complexity for every approach.
- Revisit older solutions when a clearer or more efficient approach is found.
- Add new solutions in Dart, C, C++, or Python to the appropriate difficulty folder.

## Progress Log

Progress is tracked through the solution files and Git history. Each commit represents another step in the daily practice habit.
